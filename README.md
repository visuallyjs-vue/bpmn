# BPMN - VisuallyJs Vue

BPMN (Business Process Model and Notation) is a standard graphical representation for specifying business processes in a business process model. It provides a common language for business users and technical developers, using a set of standardized symbols to represent tasks, events, gateways, and the flow of information between them.
